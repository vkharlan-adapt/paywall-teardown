# Changelog

## 1.1.0 — 2026-10-17

- Paywall score: a 100-point rubric across six dimensions (value clarity,
  pricing clarity, visual hierarchy, trust & proof, CTA, offer & nudges).
  Every check is full / half / zero points, so re-runs of the same screenshot
  land on the same number.
- Report card: a shareable PNG with numbered callouts on the screenshot,
  the score, dimension bars, and the ranked tests.
- Four visual patterns added to the library: single focal point / scan path,
  CTA placement (fold and thumb zone), legibility and contrast, value-block
  density.
- Re-run mode: a second screenshot of the same paywall opens with the score
  change.
- Packaged as a Claude Code plugin marketplace; a GitHub release builds the
  zip for claude.ai.

## 1.0.0

- First version: 15 paywall patterns, category playbooks, ranked hypotheses
  table with expected impact.
